## 1. 趋势指标

### 1.1 SMA (Simple Moving Average) - 简单移动平均线

**类别**：趋势指标
**难度**：⭐ 简单

**公式**：
```
SMA = (P1 + P2 + ... + Pn) / n
```
其中 P 为价格，n 为周期

**参数**：
- `column`: 价格列（通常是收盘价）
- `period`: 计算周期（常用：5, 10, 20, 50, 100, 200）

**用途**：
- 识别价格趋势方向
- 支撑和阻力位参考
- 生成交易信号（金叉/死叉）

**交易信号**：
- 金叉：短期均线上穿长期均线，买入信号
- 死叉：短期均线下穿长期均线，卖出信号

**代码示例**：
```python
df = TrendIndicators.sma(df, '收盘价', 20)  # 20日均线
```

---

### 1.2 EMA (Exponential Moving Average) - 指数移动平均线

**类别**：趋势指标
**难度**：⭐⭐ 中等

**公式**：
```
EMA_today = α × Price_today + (1 - α) × EMA_yesterday
α = 2 / (period + 1)
```

**参数**：
- `column`: 价格列
- `period`: 计算周期（常用：5, 10, 12, 20, 26, 50）

**用途**：
- 对近期价格变化更敏感
- 短期趋势跟踪
- MACD指标的基础

**优势**：
- 比SMA反应更快
- 减少滞后性

**代码示例**：
```python
df = TrendIndicators.ema(df, '收盘价', 12)  # 12日EMA
```

---

### 1.3 WMA (Weighted Moving Average) - 加权移动平均线

**类别**：趋势指标
**难度**：⭐⭐ 中等

**公式**：
```
WMA = (n×P1 + (n-1)×P2 + ... + 1×Pn) / (n + (n-1) + ... + 1)
    = (n×P1 + (n-1)×P2 + ... + 1×Pn) / (n×(n+1)/2)
```

**参数**：
- `column`: 价格列
- `period`: 计算周期

**用途**：
- 给予近期数据更高权重
- 平滑价格波动
- 趋势确认

**特点**：
- 介于SMA和EMA之间
- 线性权重递减

**代码示例**：
```python
df = TrendIndicators.wma(df, '收盘价', 10)  # 10日WMA
```

---

### 1.4 HMA (Hull Moving Average) - 赫尔移动平均线

**类别**：高级趋势指标
**难度**：⭐⭐⭐ 复杂

**公式**：
```
HMA = WMA(2 × WMA(n/2) - WMA(n), sqrt(n))
```

**参数**：
- `column`: 价格列
- `period`: 计算周期（常用：9, 16, 25）

**用途**：
- 减少延迟
- 提高平滑度
- 快速趋势识别

**优势**：
- 几乎消除滞后
- 保持平滑性
- 快速反应趋势变化

**代码示例**：
```python
df = AdvancedTrendIndicators.hma(df, '收盘价', 9)  # 9期HMA
```

---

### 1.5 TRIX (Triple Exponential Average) - 三重指数平滑平均线

**类别**：高级趋势指标
**难度**：⭐⭐⭐ 复杂

**公式**：
```
EMA1 = EMA(Price, period)
EMA2 = EMA(EMA1, period)
EMA3 = EMA(EMA2, period)
TRIX = (EMA3_today - EMA3_yesterday) / EMA3_yesterday × 100
```

**参数**：
- `column`: 价格列
- `period`: 计算周期（常用：15）

**用途**：
- 过滤短期波动
- 识别长期趋势
- 超买超卖判断

**交易信号**：
- TRIX上穿零线：买入
- TRIX下穿零线：卖出
- 背离：趋势反转信号

**代码示例**：
```python
df = AdvancedTrendIndicators.trix(df, '收盘价', 15)  # 15期TRIX
```

---

### 1.6 VWMA (Volume Weighted Moving Average) - 成交量加权移动平均

**类别**：高级趋势指标
**难度**：⭐⭐ 中等

**公式**：
```
VWMA = Σ(Price × Volume) / Σ(Volume)
```

**参数**：
- `price_col`: 价格列
- `volume_col`: 成交量列
- `period`: 计算周期

**用途**：
- 考虑成交量的趋势分析
- 识别真实价格趋势
- 过滤虚假突破

**特点**：
- 大成交量的价格权重更高
- 更能反映市场真实意图

**代码示例**：
```python
df = AdvancedTrendIndicators.vwma(df, '收盘价', '成交量', 10)
```

## 2. 动量指标

### 2.1 RSI (Relative Strength Index) - 相对强弱指标

**类别**：动量指标
**难度**：⭐⭐ 中等

**公式**：
```
RS = 平均涨幅 / 平均跌幅
RSI = 100 - (100 / (1 + RS))
```

**参数**：
- `column`: 价格列
- `period`: 计算周期（默认：14）

**用途**：
- 判断超买超卖
- 识别背离
- 趋势强度确认

**交易信号**：
- RSI > 70：超买，可能回调
- RSI < 30：超卖，可能反弹
- 50为中线，上方看多，下方看空

**注意事项**：
- 强势趋势中会钝化
- 需结合其他指标确认

**代码示例**：
```python
df = MomentumIndicators.rsi(df, '收盘价', 14)  # 14日RSI
```

---

### 2.2 Momentum - 动量指标

**类别**：动量指标
**难度**：⭐ 简单

**公式**：
```
Momentum = Price_today - Price_n_days_ago
```

**参数**：
- `column`: 价格列
- `period`: 回溯周期（常用：5, 10, 20）

**用途**：
- 衡量价格变化速度
- 识别趋势强度
- 预测趋势持续性

**交易信号**：
- 动量为正且增大：上涨加速
- 动量为负且减小：下跌加速
- 动量接近零：趋势减弱

**代码示例**：
```python
df = MomentumIndicators.momentum(df, '收盘价', 10)  # 10日动量
```

---

### 2.3 ROC (Rate of Change) - 变动率指标

**类别**：动量指标
**难度**：⭐ 简单

**公式**：
```
ROC = (Price_today - Price_n_days_ago) / Price_n_days_ago × 100
```

**参数**：
- `column`: 价格列
- `period`: 回溯周期

**用途**：
- 百分比形式的动量
- 不同股票间可比较
- 超买超卖判断

**交易信号**：
- ROC > 0：上涨
- ROC < 0：下跌
- |ROC| > 10%：强势行情

**代码示例**：
```python
df = MomentumIndicators.roc(df, '收盘价', 12)  # 12日ROC
```

---

### 2.4 CMO (Chande Momentum Oscillator) - 钱德动量摆动指标

**类别**：动量指标
**难度**：⭐⭐ 中等

**公式**：
```
CMO = 100 × (Sum(up) - Sum(down)) / (Sum(up) + Sum(down))
```

**参数**：
- `column`: 价格列
- `period`: 计算周期（默认：14）

**用途**：
- 识别超买超卖
- 背离分析
- 趋势强度判断

**交易信号**：
- CMO > +50：超买
- CMO < -50：超卖
- 范围：-100 到 +100

**优势**：
- 比RSI更敏感
- 考虑价格方向和强度

**代码示例**：
```python
df = MomentumIndicators.cmo(df, '收盘价', 14)  # 14日CMO
```

## 3. 波动率指标

### 3.1 Bollinger Bands - 布林带

**类别**：波动率指标
**难度**：⭐⭐ 中等

**公式**：
```
中轨 = SMA(Price, period)
上轨 = 中轨 + k × StdDev
下轨 = 中轨 - k × StdDev
```

**参数**：
- `column`: 价格列
- `period`: 计算周期（默认：20）
- `num_std`: 标准差倍数（默认：2.0）

**用途**：
- 判断价格相对高低
- 识别突破
- 波动率分析

**交易信号**：
- 价格触及上轨：可能回调
- 价格触及下轨：可能反弹
- 带宽收窄：波动率降低，可能突破

**代码示例**：
```python
df = VolatilityIndicators.bollinger_bands(df, '收盘价', 20, 2.0)
# 输出：BB_Upper, BB_Middle, BB_Lower
```

---

### 3.2 ATR (Average True Range) - 平均真实波幅

**类别**：波动率指标
**难度**：⭐⭐ 中等

**公式**：
```
TR = max(High - Low, |High - Close_prev|, |Low - Close_prev|)
ATR = EMA(TR, period)
```

**参数**：
- `high_col`, `low_col`, `close_col`: 价格列
- `period`: 计算周期（默认：14）

**用途**：
- 衡量波动性
- 设置止损位
- 头寸规模调整

**特点**：
- 绝对值，非归一化
- 不指示方向，只衡量波动

**代码示例**：
```python
df = VolatilityIndicators.atr(df, '最高', '最低', '收盘价', 14)
```

---

### 3.3 Volatility - 波动率

**类别**：波动率指标
**难度**：⭐ 简单

**公式**：
```
Volatility = StdDev(Price, period)
```

**参数**：
- `column`: 价格列
- `period`: 计算周期

**用途**：
- 衡量价格波动程度
- 风险评估
- 期权定价参考

**代码示例**：
```python
df = VolatilityIndicators.volatility(df, '收盘价', 10)
```

---

### 3.4 Keltner Channels - 肯特纳通道

**类别**：高级波动率指标
**难度**：⭐⭐⭐ 复杂

**公式**：
```
中轨 = EMA(Close, period)
上轨 = 中轨 + multiplier × ATR
下轨 = 中轨 - multiplier × ATR
```

**参数**：
- `high_col`, `low_col`, `close_col`: 价格列
- `ema_period`: EMA周期（默认：20）
- `atr_period`: ATR周期（默认：10）
- `multiplier`: ATR倍数（默认：2.0）

**用途**：
- 趋势跟踪
- 突破交易
- 支撑阻力识别

**vs 布林带**：
- 使用ATR而非标准差
- 更适合趋势市场

**代码示例**：
```python
df = AdvancedVolatilityIndicators.keltner_channels(df, '最高', '最低', '收盘价', 20, 10, 2.0)
# 输出：KC_Upper, KC_Middle, KC_Lower
```

---

### 3.5 Donchian Channel - 唐奇安通道

**类别**：高级波动率指标
**难度**：⭐⭐ 中等

**公式**：
```
上轨 = max(High, period)
下轨 = min(Low, period)
中轨 = (上轨 + 下轨) / 2
```

**参数**：
- `high_col`, `low_col`: 价格列
- `period`: 计算周期（默认：20）

**用途**：
- 识别突破
- 趋势跟踪
- 海龟交易法则的核心

**交易策略**：
- 突破上轨：买入
- 突破下轨：卖出
- 回到中轨：平仓

**代码示例**：
```python
df = AdvancedVolatilityIndicators.donchian_channel(df, '最高', '最低', 20)
# 输出：DC_Upper, DC_Middle, DC_Lower
```

---

### 3.6 True Range % - 真实波幅百分比

**类别**：高级波动率指标
**难度**：⭐⭐ 中等

**公式**：
```
TR = max(High - Low, |High - Close_prev|, |Low - Close_prev|)
TR% = TR / Close × 100
```

**参数**：
- `high_col`, `low_col`, `close_col`: 价格列

**用途**：
- 归一化的波动率
- 不同股票间可比较
- 风险评估

**代码示例**：
```python
df = AdvancedVolatilityIndicators.true_range_pct(df, '最高', '最低', '收盘价')
```

### 3.7 Mass Index - 质量指标

**类别**：高级波动率指标
**难度**：⭐⭐⭐ 复杂

**公式**：
```
Range = High - Low
EMA1 = EMA(Range, period)
EMA2 = EMA(EMA1, period)
Ratio = EMA1 / EMA2
Mass Index = Sum(Ratio, sum_period)
```

**参数**：
- `high_col`, `low_col`: 价格列
- `ema_period`: EMA周期（默认：9）
- `sum_period`: 求和周期（默认：25）

**用途**：
- 预测趋势反转
- 波动率收缩扩张分析

**交易信号**：
- Mass Index > 27：可能反转
- Mass Index < 26.5：趋势恢复

**代码示例**：
```python
df = ExtraIndicators.mass_index(df, '最高', '最低', 9, 25)
```

## 4. 成交量指标

### 4.1 OBV (On Balance Volume) - 能量潮

**类别**：成交量指标
**难度**：⭐⭐ 中等

**公式**：
```
if Close > Close_prev:
    OBV = OBV_prev + Volume
elif Close < Close_prev:
    OBV = OBV_prev - Volume
else:
    OBV = OBV_prev
```

**参数**：
- `close_col`: 收盘价列
- `volume_col`: 成交量列

**用途**：
- 确认价格趋势
- 识别背离
- 预测突破

**交易信号**：
- OBV上升 + 价格上升：确认上涨
- OBV下降 + 价格下降：确认下跌
- 背离：趋势可能反转

**代码示例**：
```python
df = VolumeIndicators.obv(df, '收盘价', '成交量')
```

---

### 4.2 Volume SMA - 成交量移动平均

**类别**：成交量指标
**难度**：⭐ 简单

**公式**：
```
Volume_SMA = SMA(Volume, period)
```

**参数**：
- `volume_col`: 成交量列
- `period`: 计算周期

**用途**：
- 识别放量缩量
- 确认突破有效性
- 趋势确认

**代码示例**：
```python
df = VolumeIndicators.volume_sma(df, '成交量', 20)
```

---

### 4.3 VWAP (Volume Weighted Average Price) - 成交量加权平均价

**类别**：成交量指标
**难度**：⭐⭐ 中等

**公式**：
```
Typical Price = (High + Low + Close) / 3
VWAP = Σ(Typical Price × Volume) / Σ(Volume)
```

**参数**：
- `high_col`, `low_col`, `close_col`: 价格列
- `volume_col`: 成交量列

**用途**：
- 日内交易参考价
- 大单成本估算
- 支撑阻力位

**交易策略**：
- 价格 > VWAP：多头占优
- 价格 < VWAP：空头占优

**代码示例**：
```python
df = VolumeIndicators.vwap(df, '最高', '最低', '收盘价', '成交量')
```

---

### 4.4 CMF (Chaikin Money Flow) - 蔡金资金流量

**类别**：高级成交量指标
**难度**：⭐⭐⭐ 复杂

**公式**：
```
Money Flow Multiplier = ((Close - Low) - (High - Close)) / (High - Low)
Money Flow Volume = MF Multiplier × Volume
CMF = Sum(MF Volume, period) / Sum(Volume, period)
```

**参数**：
- `high_col`, `low_col`, `close_col`: 价格列
- `volume_col`: 成交量列
- `period`: 计算周期（默认：20）

**用途**：
- 资金流向分析
- 买卖压力判断
- 背离分析

**交易信号**：
- CMF > 0：买盘压力
- CMF < 0：卖盘压力
- 范围：-1 到 +1

**代码示例**：
```python
df = AdvancedVolumeIndicators.cmf(df, '最高', '最低', '收盘价', '成交量', 20)
```

---

**交易信号**：

```python
df = AdvancedVolumeIndicators.fi(df, '收盘价', '成交量', 13)
```

### 4.8 ADL (Accumulation/Distribution Line) - 聚散指标

**难度**：⭐⭐ 中等

**参数**：

**用途**：

- ADL下降：派发（卖出）
- 背离：趋势反转信号

```python
df = ExtraIndicators.adl(df, '最高', '最低', '收盘价', '成交量')
```

## 5. 震荡指标

### 5.1 MACD (Moving Average Convergence Divergence) - 指数平滑异同移动平均线

**类别**：震荡指标
**难度**：⭐⭐ 中等

**公式**：
```
MACD Line = EMA(Close, 12) - EMA(Close, 26)
Signal Line = EMA(MACD Line, 9)
Histogram = MACD Line - Signal Line
```

**参数**：
- `column`: 价格列

### 5.3 CCI (Commodity Channel Index) - 顺势指标

**类别**：震荡指标
**难度**：⭐⭐ 中等

**公式**：
```
Typical Price = (High + Low + Close) / 3
CCI = (Typical Price - SMA(Typical Price, period)) / (0.015 × Mean Absolute Deviation)
```

**参数**：
- `high_col`, `low_col`, `close_col`: 价格列
- `period`: 计算周期（默认：20）

**用途**：
- 识别超买超卖
- 趋势强度判断
- 背离分析

**交易信号**：
- CCI > +100：超买
- CCI < -100：超卖
- 穿越零线：趋势变化

**代码示例**：
```python
df = OscillatorIndicators.cci(df, '最高', '最低', '收盘价', 20)
```

### 5.4 Aroon - 阿隆指标

**类别**：高级震荡指标
**难度**：⭐⭐⭐ 复杂

**公式**：
```
Aroon Up = ((period - days_since_highest_high) / period) × 100
Aroon Down = ((period - days_since_lowest_low) / period) × 100
Aroon Oscillator = Aroon Up - Aroon Down
```

**参数**：
- `high_col`, `low_col`: 价格列
- `period`: 计算周期（默认：25）

**用途**：
- 识别趋势开始
- 趋势强度判断
- 趋势方向确认

**交易信号**：
- Aroon Up > 70 且 Aroon Down < 30：强上涨趋势
- Aroon Down > 70 且 Aroon Up < 30：强下跌趋势
- 两者都 < 50：盘整

**代码示例**：
```python
df = AdvancedOscillatorIndicators.aroon(df, '最高', '最低', 25)
# 输出：Aroon_Up, Aroon_Down, Aroon_Oscillator
```

### 5.5 Ultimate Oscillator - 终极震荡指标

**类别**：高级震荡指标
**难度**：⭐⭐⭐⭐ 很复杂

**公式**：
```
Buying Pressure = Close - min(Low, Close_prev)
True Range = max(High, Close_prev) - min(Low, Close_prev)
Average7 = Sum(BP, 7) / Sum(TR, 7)
Average14 = Sum(BP, 14) / Sum(TR, 14)
Average28 = Sum(BP, 28) / Sum(TR, 28)
UO = 100 × (4×Average7 + 2×Average14 + Average28) / 7
```

**参数**：
- `high_col`, `low_col`, `close_col`: 价格列
- `period1`, `period2`, `period3`: 三个周期（默认：7, 14, 28）

**用途**：

- 超买超卖判断
- 背离分析

**交易信号**：
- UO > 70：超买
- UO < 30：超卖
- 背离：反转信号

**代码示例**：

```python
df = AdvancedOscillatorIndicators.ultimate_oscillator(df, '最高', '最低', '收盘价', 7, 14, 28)
```

### 5.7 TSI (True Strength Index) - 真实强度指标

**类别**：高级震荡指标
**难度**：⭐⭐⭐ 复杂

**公式**：
```
PC = Price_Change = Close - Close_prev
Double_Smoothed_PC = EMA(EMA(PC, long_period), short_period)
Double_Smoothed_APC = EMA(EMA(|PC|, long_period), short_period)
TSI = 100 × Double_Smoothed_PC / Double_Smoothed_APC
```

**参数**：
- `column`: 价格列
- `long_period`: 长期周期（默认：25）
- `short_period`: 短期周期（默认：13）

**用途**：
- 趋势方向和力量
- 超买超卖判断
- 交易信号生成

**交易信号**：
- TSI > 0：多头
- TSI < 0：空头
- TSI上穿信号线：买入

**代码示例**：
```python
df = AdvancedOscillatorIndicators.tsi(df, '收盘价', 25, 13)
```

## 12. 使用建议

### 12.1 指标组合建议

**趋势跟踪组合**：
- SMA(50) + SMA(200)：长期趋势
- EMA(12) + EMA(26)：短期趋势
- MACD：趋势确认

**超买超卖组合**：
- RSI(14)
- Stochastic(14,3)
- Williams %R

**成交量确认组合**：
- OBV
- CMF
- Volume SMA

**波动率分析组合**：
- Bollinger Bands
- ATR
- Keltner Channels

### 12.2 不同市场环境的指标选择

**趋势市场**：
- 移动平均线
- MACD
- ADX

**震荡市场**：
- RSI
- Stochastic
- Bollinger Bands

**突破交易**：
- Donchian Channel
- ATR
- Volume indicators

### 12.3 参数优化建议

**常用周期**：
- 短期：5-14天
- 中期：20-50天
- 长期：100-200天

**参数调整原则**：
- 波动大的市场：增大周期
- 波动小的市场：减小周期
- 回测验证：使用历史数据测试

### 12.4 注意事项

1. **指标钝化**：强势趋势中，超买超卖指标会钝化
2. **背离信号**：价格和指标方向不一致时，注意反转
3. **多重确认**：使用多个指标相互确认
4. **参数敏感性**：不同参数结果差异大，需要测试
5. **滞后性**：大多数指标都有滞后，不能单独依赖

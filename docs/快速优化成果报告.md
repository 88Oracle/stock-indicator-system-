## 💻 快速使用

### 方式1: 默认优化模式（推荐）

```python
from src.core.data_processor import DataProcessor, IndicatorCalculator, ResultSaver

# 1. 初始化（自动开启所有优化）
processor = DataProcessor("data/stock_data.duckdb")

# 2. 读取数据（只读14核心列）
df = processor.read_data_polars()

# 3. 计算指标
df_with_indicators = IndicatorCalculator.calculate_all_indicators_polars(df)

# 4. 快速保存（zstd压缩level1）
ResultSaver.save_to_parquet(df_with_indicators, "output/result.parquet")
```

### 方式2: 关闭优化（如需全部列）

```python
# 读取全部243列
processor = DataProcessor("data/stock_data.duckdb", use_essential_columns=False)
df = processor.read_data_polars()

# 标准保存模式
ResultSaver.save_to_parquet(df, "output/result.parquet", fast_mode=False)
```

## ⚡ 核心优化技术

### 1. 列裁剪（Column Pruning）
- 从243列 → 14列
- 数据传输量减少94%
- **这是最大的性能提升来源**

### 2. 快速压缩算法
- 使用zstd替代snappy
- 压缩级别降至1（最快）
- 跳过统计信息计算

### 3. 内存优化
- 减少中间数据复制
- 添加列名别名而非重复数据
- 自动内存布局优化(rechunk)

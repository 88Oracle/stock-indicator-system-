## ✅ 已实施的优化

### 优化1: 只读取必要的列（15/243列）

**原理**:
- 从243列减少到15个核心列
- 数据量减少94%
- 读取和处理速度显著提升

**使用方法**:

```python
from src.core.data_processor import DataProcessor

# 方式1: 默认开启优化（推荐）
processor = DataProcessor("data/stock_data.duckdb")
df = processor.read_data_polars()  # 只读15核心列

# 方式2: 如需读取全部列
processor = DataProcessor("data/stock_data.duckdb", use_essential_columns=False)
df = processor.read_data_polars()  # 读取全部243列
```

**核心列列表**:
```python
ESSENTIAL_COLUMNS = [
    '日期', '代码', '名称',           # 基础信息
    '收盘价', '开盘价', '最高', '最低',  # OHLC价格
    '今开',                            # 开盘价别名
    '总量', '总金额',                  # 成交量
    '涨幅%', '振幅%',                  # 基础指标
    '换手%', '量比',                   # 辅助指标
    '昨收'                             # 用于计算
]
```

### 优化2: Parquet快速保存模式

**原理**:
- 使用zstd压缩算法（比snappy更快）
- 压缩级别设为1（最快）
- 跳过统计信息计算
- 减小行组大小加快写入

**使用方法**:

```python
from src.core.data_processor import ResultSaver

# 方式1: 快速模式（推荐，默认）
ResultSaver.save_to_parquet(df, "output/result.parquet")
# 或明确指定
ResultSaver.save_to_parquet(df, "output/result.parquet", fast_mode=True)

# 方式2: 标准模式（如需更高压缩率）
ResultSaver.save_to_parquet(df, "output/result.parquet", fast_mode=False)
```

**参数对比**:

| 参数 | 快速模式 | 标准模式 |
|-----|---------|---------|
| 压缩算法 | zstd | snappy |
| 压缩级别 | 1（最快） | 3（默认） |
| 统计信息 | 跳过 | 计算 |
| 行组大小 | 10,000 | 默认 |
| **速度** | ⚡⚡⚡ | ⚡ |
| **文件大小** | 稍大 | 较小 |

### 优化4: CSV直接读取（跳过DuckDB）

**原理**:
- 省去 CSV→DuckDB→Arrow→Polars 的转换
- 使用Polars原生CSV读取器
- 性能提升最明显（50%+）

**使用方法**:

```python
from src.core.data_processor import DataProcessor

processor = DataProcessor("data/stock_data.duckdb")

# 新方法：直接从CSV读取（推荐）
df = processor.read_csv_direct()  # 自动查找CSV文件

# 指定CSV路径
df = processor.read_csv_direct(csv_path="data/通达信数据_20251229.csv")

# 限制行数
df = processor.read_csv_direct(limit=100000)

# 旧方法：通过DuckDB读取
df = processor.read_data_polars()
```

**适用场景**:
- ✅ 首次数据处理
- ✅ 不需要SQL查询
- ✅ 追求最快速度
- ❌ 需要复杂SQL筛选（用DuckDB）

## ⚠️ 注意事项

### 1. 列缺失问题

如果某些高级指标需要额外列：

```python
# 方法1: 关闭列优化
processor = DataProcessor(db_path, use_essential_columns=False)

# 方法2: 在ESSENTIAL_COLUMNS中添加所需列
```

### 2. CSV编码问题

如果CSV文件有编码问题：

```python
df = pl.read_csv(
    csv_path,
    encoding='gbk',  # 或 'gb18030', 'utf8'
    ignore_errors=True
)
```

### 3. 内存使用

```python
# 如果内存不足，使用分块处理
for chunk in range(0, 1000000, 100000):
    df = processor.read_csv_direct(limit=100000)
    # 处理chunk...
```
